Premières actions en cas d'attaque de ransomware

Rançongiciel ou attaque en cours : les premières actions

Ces actions suivent les « bons réflexes » du guide de l'ANSSI Attaques par rançongiciels, tous concernés, adaptés à un cabinet ou à un établissement de santé.

  1. Couper les connexions Internet du réseau attaqué. En établissement : couper les routeurs de bordure (liens Internet). En cabinet : débrancher la box Internet. L'attaquant ne peut plus piloter son rançongiciel ni lancer une nouvelle vague.
  2. Identifier et isoler les machines touchées : débrancher le câble réseau, couper le Wi-Fi, ou isoler par VLAN en établissement. Déconnecter les sauvegardes reliées au réseau (disque USB branché, NAS) pour les protéger du chiffrement.
  3. Ne pas éteindre les machines touchées : on perdrait les données en mémoire vive (clés, processus, connexions), utiles à l'enquête.
  4. Ne pas démarrer les machines restées éteintes.
  5. Conserver les preuves (journaux, images mémoire et disque), si possible par un professionnel (prestataire qualifié PRIS). Ouvrir tout de suite une main courante : heure, constats, actions menées, personnes prévenues.
  6. Alerter :
    • la direction et le service ou prestataire informatique
    • le CERT Santé pour une structure de santé (déclaration obligatoire pour les établissements)
    • Practilio si des comptes Practilio sont concernés
    • la CNIL sous 72 h si des données de patients sont touchées
    Le détail est sur la page Qui contacter.
  7. Ne pas payer la rançon : rien ne garantit la restitution des données, et cela finance les criminels.
  8. Déposer plainte auprès de la police ou de la gendarmerie, dans les 72 heures si vous voulez être indemnisé par votre assurance (art. L.12-10-1 du Code des assurances). La plainte permet aussi l'ouverture d'une enquête, qui peut aboutir à la récupération de clés de déchiffrement.
  • Pour une structure de santé, le point d'entrée de l'alerte est le CERT Santé, qui se coordonne avec l'ANSSI/CERT-FR.
  • Pour une petite structure, le point d'entrée est 17Cyber.

Bon à savoir : l'ANSSI a développé un logiciel de collecte d'informations, DFIR ORC, publié en open source. Il rassemble les traces techniques d'un poste Windows (journaux, registre, fichiers système) sans les analyser, pour l'enquête menée ensuite par des spécialistes. Il est notamment utilisé par le CERT Santé. DFIR ORC sur GitHub
